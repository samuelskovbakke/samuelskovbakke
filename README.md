## 🧑‍💻 About me

I'm based in Aarhus, Denmark 🇩🇰, with a Master's in Computer Science specialising in programming languages and cryptology 🔐. I'm a huge fan of Nix ❄️, functional programming, and writing compilers that actually explain themselves 🧙.

- 🎓 **Master's thesis:** [*Tracing Effect Mismatches*](https://github.com/flix/flix/pull/12627). Three iterative approaches (effect-flow graphs, lattice-based analysis, Zhegalkin polynomials) to turn Flix's raw Boolean-algebra effect errors into actionable diagnostics.
- 🐧 Daily-driving **NixOS** across desktop and laptop with the Niri Wayland compositor. Fully declarative, reproducible setup.

When I'm not deep in a NixOS config or contributing to open source, I can be found watching anime 📺, gaming with friends 🎮, or tinkering with my dotfiles for the hundredth time 🔧.
